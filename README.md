# Top-Down 2D Collectathon

A 2D top-down collectathon game developed using Unity.

## About the Project

This project is a top-down 2D game created while learning Unity.
The player explores the environment and collects objects.

## Features

- Top-down 2D gameplay
- Player movement
- Collectible objects
- Environment exploration
- Unity-based game development

## Built With

- Unity
- C#

## How to Open the Project

1. Install a compatible version of Unity.
2. Create or open a Unity project.
3. Download `TopDown2D_Collectathon.unitypackage` from this repository.
4. In Unity, select Assets > Import Package > Custom Package.
5. Select the downloaded package and import its contents.
6. Locate and open the `5_TopDown_2D_Scene` scene.
